# Min Poe Zin Win Personal Brand

This repository contains the Next.js + TypeScript starter for the personal branding site for Min Poe Zin Win.

Quick start:

1. Copy `.env.example` to `.env.local` and set the variables (DATABASE_URL, NEXTAUTH_SECRET, Cloudinary keys).
2. Install dependencies: `npm install`
3. Generate Prisma client and push schema: `npx prisma generate && npx prisma db push`
4. Run dev server: `npm run dev`

Seed admin user: you can create an admin manually or run a seed script (not included in this initial scaffold).
